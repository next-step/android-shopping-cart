# android-shopping-cart

## 1단계
- [x] 상품목록 탑 앱바를 구현한다
- [x] 상품을 표시할 아이템뷰를 구현한다
- [x] 상품들을 표시할 리스트를 구현한다
- [x] 구현한 컴포넌트들을 사용해 screen을 구현한다

## 2단계
### 공통
- [x] 상품 상세와 장바구니에서 사용할 탑 앱바를 구현한다

### 상품 목록
- [ ] 상품을 누르면 상품 상세 화면으로 이동한다
- [x] 장바구니 아이콘을 누르면 장바구니 화면으로 이동한다

### 상품 상세
- [ ] 상품 상세 정보 뷰를 구현한다
- [ ] 뒤로 가기 버튼이나 아이콘을 누르면 직전 화면으로 돌아간다
- [ ] 장바구니 담기 버튼을 누르면 장바구니 화면으로 이동한다

### 장바구니
- [x] 뒤로 가기 버튼을 누르면 직전 화면으로 돌아간다
