# android-shopping-cart

🚀 1단계 - 장바구니(상품 목록)
- coil 라이브러리 추가
- 상품 데이터 모델 추가
- 상품 아이템 컴포넌트 추가
- 앱바 추가
- 상품 목록 추가

🚀 2단계 - 장바구니(상품 상세)
- 상품 상세 화면 추가
- 장바구니 화면 추가
- 상품 리스트에서 상품 상세로 이동
- 상품 상세 뒤로가기 추가
- 상품 데이터 상세 화면에 그리기
- 상품 리스트에서 장바구니로 이동
- 장바구니 뒤로가기 추가
- 테스크 코드 추가

🚀 3단계 - 장바구니(담기)
- 장바구니 상품 컴포저블 추가
- 상품 상세 페이지에서 장바구니 담기 기능 추가
- 수량 조절 컴포저블 함수 분리
- 수량 조절 시 총합 가격 표시
- 장바구니에서 상품 삭제 기능 추가
- 상품 수량을 1보다 작게 하면 장바구니에서 상품이 제거
- 테스트 코드 추가
- 피드백 반영
  - 테스트 케이스 추가
  - 컴포즈 함수 파라미터 순서 컨벤션 맞추기
  - 파라미터 기본 required 고민하여 수정하기
  - CompositionLocal 공부하기
  - 이미지, 이름, 가격 각각의 정보를 이미 정의된 모델을 활용하여 전달 받기
  - ProductDetailScreen 컴포넌트 역할 분리해보기

🚀 4단계 - 장바구니(수량)
- 상품 목록 페이지에서 상품 아이템 Ui 에 '+' 버튼 추가
- '+' 버튼 클릭 시 수량 1개 증가
- '+' 버튼 클릭 시 상품 수량 조절 Ui 로 변경
- 상품 수량 조절 Ui 에서 '-' 버튼 클릭 시 0개가 된다면 '+' 버튼으로 변경
- 테스트 코드 추가
- 피드백 반영
  - 수량 조절 컴포넌트의 내부에서 더 작은 컴포넌트로 분리
  - ProductPrice 컴포넌트 테스트 코드 추가
  - LazyColumn 요소에 id 부여
  - Preview 에서 다른 객체영향 받지 않도록 리스트를 직접 생성하여 전달
  - 상태를 가지는 CartScreen 컴포저블 함수를 오버로딩을 활용하여 만들어보기
