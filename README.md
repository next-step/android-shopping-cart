# android-shopping-cart

## 1단계
- [x] 상품목록 탑 앱바를 구현한다
- [x] 상품을 표시할 아이템뷰를 구현한다
- [x] 상품들을 표시할 리스트를 구현한다
- [x] 구현한 컴포넌트들을 사용해 screen을 구현한다

## 2단계
### 공통
- [x] 상품 상세와 장바구니에서 사용할 탑 앱바를 구현한다

### 상품 목록
- [x] 상품을 누르면 상품 상세 화면으로 이동한다
- [x] 장바구니 아이콘을 누르면 장바구니 화면으로 이동한다

### 상품 상세
- [x] 상품 상세 정보 뷰를 구현한다
- [x] 뒤로 가기 버튼이나 아이콘을 누르면 직전 화면으로 돌아간다
- [x] 장바구니 담기 버튼을 누르면 장바구니 화면으로 이동한다

### 장바구니
- [x] 뒤로 가기 버튼을 누르면 직전 화면으로 돌아간다

## 3단계
- [ ] 장바구니 리스트 아이템 뷰를 구현한다
  - [x] -와 +를 가지고 숫자를 보여주는 버튼 뷰(Stepper)를 구현한다
- [ ] 장바구니 뷰를 구현한다
  - [ ] 전체 장바구니 상품 가격의 합을 보여주는 바텀 버튼을 구현한다
  - [ ] 장바구니 리스트를 구현한다
  - [ ] 아이템 뷰에서 X버튼을 누르면 상품이 삭제된다
  - [ ] 수량이 1보다 작으면 상품이 삭제된다
